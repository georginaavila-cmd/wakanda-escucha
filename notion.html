Conectar Notion

Para escuchar una página privada de Notion pegando su enlace, y para enviarle tus notas de voz, se preparan dos cosas una sola vez: un permiso en Notion y un puente gratuito en tu cuenta de Google. Toma unos 10 minutos y es más cómodo en el computador. Tus páginas no quedan públicas: solo quien tenga el token puede leerlas.

1Crea el permiso en Notion

  1. Entra a notion.so/profile/integrations.
  2. Toca Nueva integración (New integration). Nombre: Escucha. Elige tu espacio de trabajo, tipo Interna, y guarda.
  3. En Capacidades (Capabilities) deja marcados Leer contenido (Read content) e Insertar contenido (Insert content), y guarda los cambios. Insertar sirve para enviar tus notas de voz; la app nunca cambia ni borra lo que ya está escrito.
  4. Junto a Token secreto de integración interna (Internal Integration Secret) toca Mostrar y Copiar. Empieza por ntn_. Guárdalo para el paso 4.

2Dale acceso a tus páginas

La integración solo ve las páginas que tú le compartas. Las páginas que están dentro de una página compartida quedan incluidas.

  • Desde la integración: pestaña Acceso (Access) → Editar acceso → elige las páginas.
  • O desde cada página: toca ··· arriba a la derecha → Conexiones (Connections) → busca Escucha → Confirmar.

3Crea el puente en Google

  1. Entra a script.google.com con tu cuenta de Google. Se abre un proyecto nuevo.
  2. Arriba, cambia «Proyecto sin título» por Puente Escucha.
  3. Borra el código que aparece, pega el código de abajo del paso 6 (botón Copiar código) y guarda con el ícono del disquete.
  4. Toca Implementar (Deploy) → Nueva implementación (New deployment).
  5. En el engranaje de «Seleccionar tipo», elige Aplicación web (Web app).
  6. Ejecutar como: Yo. Quién tiene acceso: Cualquier usuario (Anyone). Toca Implementar.
  7. Google te pide autorizar: Autorizar acceso → elige tu cuenta. Si aparece «Google no verificó esta app», toca Configuración avanzada → Ir a Puente Escucha → Permitir. El aviso sale porque el código es tuyo y no lo publicó Google.
  8. Copia la URL de la aplicación web. Termina en /exec.

Si «Cualquier usuario» no aparece, tu cuenta de empresa no lo permite. Haz este paso con una cuenta personal de Gmail.

4Conecta la app

  1. Pasa la dirección del puente y el token al celular por un medio privado, por ejemplo una nota en tu correo, y bórrala después.
  2. En Escucha toca Enlace de Notion, pega la dirección del puente y el token, y toca Conectar.
  3. En Notion abre la página, toca ··· → Copiar enlace, pégalo en Escucha y toca Leer página.

Cuando cambies la página en Notion, ábrela en Escucha y toca el botón de actualizar (las dos flechas) para traer lo último.

5Tus notas de voz en Notion

Desde la sección Notas de Escucha puedes enviar cada nota a Notion. Se agrega al final de la página como una viñeta con la fecha, y debajo, en gris, el documento y la frase que estabas escuchando.

  • Si la nota es sobre un documento que viene de Notion, se agrega a esa misma página.
  • Si no, va a tu página de notas: crea en Notion una página, por ejemplo «Notas de Escucha», compártela con la integración (paso 2) y pega su enlace la primera vez que envíes una nota.

¿Ya habías creado el puente antes? Pega el código nuevo (paso 6) en tu proyecto, guarda, y en Implementar → Gestionar implementaciones toca el lápiz, elige Versión: Nueva versión e Implementar. La dirección del puente no cambia.

6Código del puente

Lee la página con la API oficial de Notion y le devuelve el texto a la app; también agrega tus notas al final de una página. No guarda el token ni el contenido.

/**
 * Puente entre la app Escucha y Notion (Google Apps Script).
 *
 * La app le manda el enlace de una página y el token de tu integración de Notion; el puente lee la
 * página con la API oficial de Notion y devuelve su texto en orden (títulos, párrafos, listas, tablas).
 * También agrega al final de una página las notas de voz que le envíes desde la app.
 * No guarda nada: ni el token ni el contenido.
 *
 * Se publica como «Aplicación web» (Ejecutar como: yo · Quién tiene acceso: cualquier usuario).
 */
var VERSION_NOTION = '2022-06-28';
var MAX_SUBPAGINAS = 25;
var MAX_NIVEL = 6;

function doGet() {
  return responder({ ok: true, app: 'Puente de Escucha para Notion' });
}

function doPost(e) {
  var pedido;
  try {
    pedido = JSON.parse(e.postData.contents);
  } catch (err) {
    return responder({ error: 'pedido' });
  }
  return responder(atender(pedido));
}

function responder(datos) {
  return ContentService.createTextOutput(JSON.stringify(datos)).setMimeType(ContentService.MimeType.JSON);
}

function atender(pedido) {
  if (!pedido || !pedido.token) return { error: 'token' };
  var api = crearApi(pedido.token);
  try {
    if (pedido.prueba) {
      var yo = api('users/me');
      return { ok: true, nombre: yo.name || 'integración' };
    }
    if (pedido.anexar) return anexarNotas(api, pedido.anexar);
    var id = idDeNotion(pedido.pagina || '');
    if (!id) return { error: 'enlace' };
    return leerPagina(api, id, !!pedido.subpaginas);
  } catch (err) {
    return { error: err.codigo || 'notion', detalle: String(err.message || err) };
  }
}

// Saca el identificador de 32 caracteres de cualquier enlace de Notion
// (notion.so, app.notion.com, notion.site, con o sin título, con ?p= de una página abierta encima).
function idDeNotion(enlace) {
  var texto = String(enlace).trim();
  var encima = texto.match(/[?&]p=([0-9a-f]{32})/i);
  var ruta = texto.split(/[?#]/)[0];
  var todos = ruta.match(/[0-9a-f]{32}|[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}/gi);
  var crudo = encima ? encima[1] : todos ? todos[todos.length - 1] : '';
  var h = crudo.replace(/-/g, '').toLowerCase();
  if (h.length !== 32) return '';
  return h.slice(0, 8) + '-' + h.slice(8, 12) + '-' + h.slice(12, 16) + '-' + h.slice(16, 20) + '-' + h.slice(20);
}

function crearApi(token) {
  return function (ruta, metodo, cuerpo) {
    var opciones = {
      method: metodo || 'get',
      headers: { Authorization: 'Bearer ' + token, 'Notion-Version': VERSION_NOTION },
      muteHttpExceptions: true,
    };
    if (cuerpo) {
      opciones.contentType = 'application/json';
      opciones.payload = JSON.stringify(cuerpo);
    }
    for (var intento = 0; intento < 4; intento++) {
      var r = UrlFetchApp.fetch('https://api.notion.com/v1/' + ruta, opciones);
      var codigo = r.getResponseCode();
      if (codigo === 429 || codigo >= 500) {
        Utilities.sleep(800 * (intento + 1));
        continue;
      }
      var datos = JSON.parse(r.getContentText() || '{}');
      if (codigo >= 400) {
        var error = new Error(datos.message || 'Notion respondió ' + codigo);
        error.codigo = traducirError(codigo, datos.code);
        throw error;
      }
      return datos;
    }
    var ocupado = new Error('Notion está ocupado');
    ocupado.codigo = 'ocupado';
    throw ocupado;
  };
}

function traducirError(codigo, code) {
  if (codigo === 401 || code === 'unauthorized') return 'token';
  if (codigo === 404 || code === 'object_not_found') return 'sin-acceso';
  if (codigo === 403 || code === 'restricted_resource') return 'sin-permiso';
  if (code === 'validation_error') return 'enlace';
  return 'notion';
}

function leerPagina(api, id, conSubpaginas) {
  var pagina;
  try {
    pagina = api('pages/' + id);
  } catch (err) {
    if (err.codigo !== 'sin-acceso' && err.codigo !== 'enlace') throw err;
    return leerBaseDeDatos(api, id, err);
  }
  var bloques = [];
  leerHijos(api, id, bloques, { nivel: 0, subpaginas: conSubpaginas, enSubpagina: false, contador: { subpaginas: 0 } });
  return { titulo: tituloDePagina(pagina), bloques: bloques, url: pagina.url };
}

// El enlace puede ser de una base de datos (una tabla de Notion): se leen los nombres de sus filas.
function leerBaseDeDatos(api, id, errorPagina) {
  var base;
  try {
    base = api('databases/' + id);
  } catch (err) {
    throw errorPagina;
  }
  var bloques = [];
  var cursor = null;
  var vueltas = 0;
  do {
    var r = api('databases/' + id + '/query', 'post', cursor ? { page_size: 100, start_cursor: cursor } : { page_size: 100 });
    r.results.forEach(function (fila) { poner(bloques, 'li', tituloDePagina(fila)); });
    cursor = r.has_more ? r.next_cursor : null;
    vueltas++;
  } while (cursor && vueltas < 5);
  return { titulo: texto(base.title) || 'Base de datos', bloques: bloques, url: base.url };
}

function tituloDePagina(p) {
  var props = (p && p.properties) || {};
  for (var k in props) {
    if (props[k] && props[k].type === 'title') return texto(props[k].title) || 'Sin título';
  }
  return 'Sin título';
}

// Las menciones (personas, fechas, páginas) llegan con «@» adelante; se quita para que la voz no diga «arroba».
function texto(rico) {
  return (rico || []).map(function (t) {
    var s = t.plain_text || '';
    return t.type === 'mention' ? s.replace(/^@/, '') : s;
  }).join('').trim();
}

function poner(salida, tipo, valor) {
  var limpio = String(valor || '').replace(/\s+/g, ' ').trim();
  if (/[\p{L}\p{N}]/u.test(limpio)) salida.push({ t: tipo, x: limpio });
}

function leerHijos(api, id, salida, ctx) {
  var cursor = null;
  do {
    var r = api('blocks/' + id + '/children?page_size=100' + (cursor ? '&start_cursor=' + encodeURIComponent(cursor) : ''));
    r.results.forEach(function (b) { convertir(api, b, salida, ctx); });
    cursor = r.has_more ? r.next_cursor : null;
  } while (cursor);
}

function convertir(api, b, salida, ctx) {
  var d = b[b.type] || {};
  var bajar = b.has_children && ctx.nivel < MAX_NIVEL;
  switch (b.type) {
    case 'heading_1':
    case 'heading_2':
    case 'heading_3':
      poner(salida, 'h', texto(d.rich_text));
      break;
    case 'paragraph':
    case 'toggle':
      poner(salida, 'p', texto(d.rich_text));
      break;
    case 'bulleted_list_item':
    case 'numbered_list_item':
      poner(salida, 'li', texto(d.rich_text));
      break;
    case 'to_do':
      poner(salida, 'li', texto(d.rich_text) + (d.checked ? ' (hecho)' : ''));
      break;
    case 'quote':
    case 'callout':
      poner(salida, 'q', texto(d.rich_text));
      break;
    case 'image':
    case 'video':
    case 'audio':
    case 'file':
    case 'pdf':
      poner(salida, 'p', texto(d.caption));
      break;
    case 'table':
      if (b.has_children) leerTabla(api, b.id, salida);
      bajar = false;
      break;
    case 'child_page':
      poner(salida, 'h', d.title);
      if (ctx.subpaginas && !ctx.enSubpagina && ctx.contador.subpaginas < MAX_SUBPAGINAS) {
        ctx.contador.subpaginas++;
        leerHijos(api, b.id, salida, { nivel: ctx.nivel + 1, subpaginas: false, enSubpagina: true, contador: ctx.contador });
      }
      bajar = false;
      break;
    case 'child_database':
      poner(salida, 'h', d.title);
      bajar = false;
      break;
    case 'code':
    case 'equation':
    case 'divider':
    case 'breadcrumb':
    case 'table_of_contents':
    case 'bookmark':
    case 'embed':
    case 'link_preview':
    case 'link_to_page':
    case 'unsupported':
      bajar = false;
      break;
    default:
      // column_list, column, synced_block, template: no tienen texto propio, solo lo que llevan adentro
      break;
  }
  if (bajar) leerHijos(api, b.id, salida, { nivel: ctx.nivel + 1, subpaginas: ctx.subpaginas, enSubpagina: ctx.enSubpagina, contador: ctx.contador });
}

function leerTabla(api, id, salida) {
  var filas = [];
  leerHijosCrudos(api, id, filas);
  filas.forEach(function (fila) {
    var celdas = ((fila.table_row || {}).cells || []).map(texto).filter(function (c) { return c; });
    if (celdas.length) poner(salida, 'p', celdas.join(', ') + '.');
  });
}

// Agrega las notas al final de la página: una viñeta por nota (fecha en negrita y el texto)
// y debajo, en gris, el documento y la frase que se estaba escuchando.
function anexarNotas(api, pedido) {
  var id = idDeNotion(pedido.pagina || '');
  if (!id) return { error: 'enlace' };
  var bloques = (pedido.notas || []).map(bloqueDeNota);
  for (var i = 0; i < bloques.length; i += 50) {
    api('blocks/' + id + '/children', 'patch', { children: bloques.slice(i, i + 50) });
  }
  return { ok: true, enviadas: bloques.length };
}

function trozosDeTexto(texto, estilo) {
  var partes = [];
  var limpio = String(texto || '');
  for (var i = 0; i < limpio.length && partes.length < 90; i += 1900) {
    var parte = { type: 'text', text: { content: limpio.slice(i, i + 1900) } };
    if (estilo) parte.annotations = estilo;
    partes.push(parte);
  }
  return partes;
}

function bloqueDeNota(nota) {
  var texto = [].concat(trozosDeTexto(String(nota.fecha || '') + ' · ', { bold: true }), trozosDeTexto(nota.texto));
  var bloque = { object: 'block', type: 'bulleted_list_item', bulleted_list_item: { rich_text: texto } };
  var sobre = nota.documento ? 'Escuchando «' + nota.documento + '»' + (nota.contexto ? ': «' + String(nota.contexto).slice(0, 400) + '»' : '') : '';
  if (sobre) {
    bloque.bulleted_list_item.children = [{
      object: 'block',
      type: 'paragraph',
      paragraph: { rich_text: trozosDeTexto(sobre, { italic: true, color: 'gray' }) },
    }];
  }
  return bloque;
}

function leerHijosCrudos(api, id, salida) {
  var cursor = null;
  do {
    var r = api('blocks/' + id + '/children?page_size=100' + (cursor ? '&start_cursor=' + encodeURIComponent(cursor) : ''));
    Array.prototype.push.apply(salida, r.results);
    cursor = r.has_more ? r.next_cursor : null;
  } while (cursor);
}
