# Wakanda Escucha

App web para escuchar en voz alta documentos (PDF, Word, exportaciones de Notion y texto copiado) desde el celular, también con la pantalla bloqueada.

**Abrir la app:** https://georginaavila-cmd.github.io/wakanda-escucha/

## Privacidad

Este repositorio solo contiene la app. Los documentos que abres, tu posición de lectura y el audio generado se quedan en tu celular (en el almacenamiento del navegador). La voz se genera dentro del teléfono: no se envía texto a ningún servidor.

## En el iPhone

1. Abre el enlace en Safari.
2. Toca Compartir → «Agregar a pantalla de inicio» para tenerla como una app.
3. Descarga la voz una vez (unos 75 MB, mejor con WiFi).
